# Pacote privado OfficeGest

Estado: rascunho 0.1.0, ainda não distribuível. Exclusivo para uso interno da equipa.

O manifesto acrescenta um separador, verificações locais e guia manual. Não contém executáveis, credenciais, dumps nem código do sistema OfficeGest. Não instala nem arranca o ambiente automaticamente.

O ZIP final terá apenas `manifest.json`, para instalar em Pacotes de integração. Esse suporte está em desenvolvimento no Meu Ubuntu e ainda não existe no binário 1.0.0-rc.1 entregue aos testadores. Validar e gerar uma nova versão da aplicação antes de distribuir este pacote.
