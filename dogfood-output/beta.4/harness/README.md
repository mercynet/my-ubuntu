# Ponte de teste da interface

Assets de produção da beta.4, copiados sem alteração. `data.js` contém o catálogo e perfis desta revisão. `bridge.js` simula a ponte Wails e conserva preferências no armazenamento do navegador.

Esta ponte permite verificar interações, marcação, filtros, edição e checklists. Não valida instalação, autenticação nem execução do backend. Essas verificações são documentadas separadamente no relatório, com testes Go, aplicação nativa e containers descartáveis.
